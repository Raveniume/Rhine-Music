# 0.4.16 验证记录

2026-10-29。Windows 生产 WebView2，隔离配置、合成歌单和静音音频；未读取私人曲库或账号。界面源提交为 `22e6c94`。

## 已验证

- TypeScript、生产前端构建和 Tauri release 构建通过；Mac 发布脚本语法检查通过。
- 原生桌面回归覆盖 1024×768、1280×800、1440×900、1920×1080，以及详情三个选项卡。顶部独立图标中心线与等距断言通过，实际截图确认歌词开关只有图标高亮。
- 点击歌词快捷开关后，原生歌词窗口隐藏；再次点击能恢复。托盘隐藏/恢复回归通过。
- 从搜索结果打开正在播放的歌曲详情，再返回，可恢复原歌单与选中歌曲。
- 正反向滚轮共采样 310 帧，计数器容器顶部始终为 780 CSS 像素；结束时没有容器基线跳动。
- 重复进入歌单和低帧率导航回归通过，运行时错误为零。详情频谱缩至 56 CSS 像素，检查了歌词底部渐隐及控件布局。
- 当前截图和原始结果保存在本机 `artifacts/current-native-ux`，不随公开包分发。

**Windows UI runtimeChecked=true。** 上述结论限于本次合成数据与测试设备，不代表所有显卡、账号接口或长期切屏场景均已覆盖。
