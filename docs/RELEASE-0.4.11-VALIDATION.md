# 0.4.11 Windows 验证记录

日期：2026-10-27。使用隔离配置、合成曲目和静音音频。

## 低帧率修订

安装版回归发现原有每帧 50 ms 的时间上限会在低于 20 FPS 时拉长镜头、抽卡和文字遮罩。音乐场景使用解析弹簧和多项式轨迹，现按真实帧间隔推进；主窗口隐藏及恢复时重置时钟。原完整开场和非音乐场景仍保留原来的处理，画质参数不变。

- TypeScript / Vite 构建通过；运动、镜头、歌单导航、速度与页面状态检查 29 项通过，包含 10 FPS 和 0.25 / 1 / 3 倍速度。
- 原生 WebView2 四种尺寸回归通过；第三次歌单入口人为限制到约 10 FPS，遮罩按时完成，没有第二次重播，右上角歌词没有隐藏帧。
- [任务栏与托盘修复记录](RELEASE-0.4.10-VALIDATION.md)及 [其余界面与性能记录](RELEASE-0.4.9-VALIDATION.md)继续适用。旧版本暴露的失败及修订原因均保留记录。
