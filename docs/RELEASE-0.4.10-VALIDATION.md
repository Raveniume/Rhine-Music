# 0.4.10 Windows 验证记录

日期：2026-10-27。使用隔离配置、合成曲目和静音音频。未读取私人曲库或账号会话。

## 修订原因

0.4.9 安装后独立任务栏检查发现：外框虽为 600×60 物理像素，Windows 恢复窗口后却可能留下标题栏边距，实际内容区只有 578×9。等待重排无法恢复，旧的“窗口可见”检查不足以发现此问题。0.4.9 已改为预发布，保留原提交、标签和安装包。

0.4.10 在原生恢复及检测到内容区尺寸异常时触发完整的无边框重算，同时将歌词和托盘浮窗排除在历史窗口状态恢复之外。回归同时核对原生外框、WebView 内容区、文字边界、屏幕命中和焦点。

## 验证范围

- 延续 [0.4.9 的界面、歌单过渡及性能检查](RELEASE-0.4.9-VALIDATION.md)，保留全部画质参数。
- 修复后的任务栏窗口为 600×60 物理像素、400×40 逻辑像素，18 CSS px 单行歌词完整显示；最小化后命中歌词窗口且不抢焦点，停止后隐藏。
- 再次冷启动、实际 Alt+Tab 和显示桌面后均通过；60 秒观察后原生命中和内容布局仍正常。
- TypeScript / Vite、Rust release 构建、3 项 Rust 几何检查通过。增强后的四种窗口尺寸回归通过，包含歌词内部高度、托盘内部高度、播放与暂停状态同步。
- 安装包及安装后验证结果将在本记录中补充。
