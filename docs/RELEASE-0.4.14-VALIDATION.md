## 完整升级仍待确认

`scripts/check-installed-update.mjs` 已准备实际旧版检测、公开 GitHub 下载、原生校验、退出旧进程、静默安装、自动重启、再次检查更新、安装清单逐文件哈希及隔离设置保留检查。启动完整验收的命令被本机会话的自动审批拒绝，未执行安装；没有通过其他命令绕过。已请用户从软件内手动触发更新后继续验证。

因此，**inAppUpdateChecked=false**。目前不能宣称 0.4.13 → 0.4.14 的应用内下载、安装和自动重启全部通过。本地安装版本在被拦截时仍为 0.4.13。原生更新脚本、实际截图和本地诊断不作为公开二进制的验收替代。

## macOS

旧自动构建没有 Developer ID、公证和 Gatekeeper 验收步骤，已收到用户“已损坏”反馈。0.4.14 不再自动上传未经验证的 Mac DMG；[Mac 接手规范](MACOS-RELEASE.md) 和 `scripts/release-macos.mjs` 包含嵌套代码签名、公证、票据、Gatekeeper 及干净下载验收要求。

Mac 签名脚本仅在 Windows 做语法和流程审查，**macOS runtimeChecked=false**。没有访问用户 Mac，也没有签名证书，不宣称已修复其现有安装包；须由 Mac 维护者执行并补充实机证据。后续 Mac 打包完善位于主分支，不改写已公开 v0.4.14 标签。
