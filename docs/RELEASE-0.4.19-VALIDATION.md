# 0.4.19 验证记录

复验日期：2026-11-09。Windows x64，WebView2，150% 系统缩放，Intel Arc 集成显卡。界面测试使用独立数据目录、合成账号和静音音频。

- 23 项歌词解析、接口回退、歌单顺序及异步请求检查通过。
- 歌单整理界面检查通过：手动调整、名称和歌曲数量排序、筛选、重开、账号隔离、1200 首歌曲虚拟列表。
- 原生窗口 1024×768、1280×800、1440×900、1920×1080 回归通过，包含图标中线、数字基线、详情间距、歌单转场和搜索返回。排序不改变当前选中的歌曲。
- 逐行和逐字歌词均使用 AMLL。逐字歌词支持渐进高亮、长音强调、点击定位、暂停、后退定位、切页恢复和深浅主题。降低动态效果时关闭缩放、模糊和弹性滚动。没有逐字时间轴时保留逐行动画，不生成虚假的逐字时间。
- 浏览器连续播放采集到 179 种字级变换、6 个逐字换行位置、18 个普通歌词换行位置。原生 Windows 静音播放 8 秒，76 次采样确认长音强调运行和 10 个换行中间位置；录屏为实际 WebView2 画面。
- 使用空账号请求公开曲目，两个样本分别返回 392、558 个逐字时间标记，另两个样本没有逐字数据。未访问用户账号、私人歌单或曲库。
- 逐字渲染测试在 700 毫秒内更新约 42 次；暂停稳定后及隐藏时，400 毫秒观察窗口内更新次数为零。
- 任务栏歌词的独立 WebView、340×40 逻辑像素布局、最小化后显示、原生命中和停止后隐藏检查通过。托盘浮窗的位置与播放控制通过原生回归。
- 生产构建与带锁文件的 Windows 原生构建通过。安装器编译通过，Microsoft WebView2 引导程序签名验证通过。
- 本机从 0.4.18 通过软件内检查更新，实际下载 GitHub 安装包、自动退出、覆盖安装并重启至 0.4.19。随后确认“已是最新版本 V0.4.19”，6,860 个文件摘要全部匹配，隔离测试配置及 WebView 存储标记保留。验收脚本在重启后的设置入口等待和 Windows 路径比较处曾失败；修正脚本后补完安装结果核验，没有再次下载或安装。

主界面 JavaScript 从约 780 KB 变为 413 KB；约 373 KB 的逐字渲染模块改为按需加载。三维画质参数没有调整。该体积变化不能直接换算成启动时间或帧率提升；首次着色器编译仍有开销。

当前截图见 `docs/media/current`。详细测试结果位于忽略的 `artifacts/current-native-ux`、`artifacts/word-lyrics`、`artifacts/desktop-ui`。
