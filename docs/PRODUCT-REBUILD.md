# RhineMusic 产品重建方案

## 产品方向

RhineMusic 是以三维档案架为首页的网易云音乐桌面播放器。主要体验是浏览真实的 3D 专辑模型、选中专辑并进入歌曲详情；二维表单只承担登录、搜索、设置和歌单管理。

## 工程基线

- 主工程采用 `DuoJiuBetter/Rhine-Music-Windows`，基线提交 `52d372c21b0e0557dea642701bf73df80c2314db`。
- 场景与音乐浏览基于 `RonaldDeng/Rhine-Music-Demo` 和 `LBEILC/RhineLabUI` 的现有实现，不另造展示性 3D 小组件。
- 保留社区版 MIT 许可、上游署名、资源来源、隐私与平台说明。代码许可不代表模型、品牌、音乐或服务接口获得额外授权。
- 平台登录首发聚焦网易云。应用启动时显示网易云账号面板并在未登录时生成二维码；QQ 音乐和波点音乐入口不显示。

## 交付顺序

1. 完成工程切换：确认 Windows 桌面宿主、三维场景、在线服务、数据目录和来源许可均来自目标仓库。
2. 完成首屏账号路径：首次启动即显示网易云扫码登录；扫码、过期、取消、重试、状态恢复和退出可理解且不泄漏凭据。
3. 完成主要使用路径：扫码后加载账号歌单，在 3D 专辑架中选择歌单和歌曲，搜索、入队、播放、暂停、切歌及歌词定位。
4. 完成场景体验：保留真实玻璃专辑模型、封面贴图、相机浏览和选择过渡；验证缩放窗口、低画质和减少动态效果。
5. 完成 Windows 交付：运行类型检查、生产构建、登录/歌单/播放检查；原生构建与安装包在可用 Windows 工具链上验证。

## 验收标准

- 冷启动第一屏可看到网易云扫码登录，不需要先寻找账号按钮。
- 登录入口不显示 QQ 音乐、波点音乐或其他平台切换。
- 扫码成功后可见账号歌单，歌单和曲目对应到真实三维专辑模型。
- 场景可旋转/滚动浏览和选择；无真实封面时保留模型结构与明确空状态。
- 登录失败、网络失败或 WebGL 初始化失败时，主界面仍给出可操作的重试路径。
- 安装包不携带个人账号、缓存、歌单数据或未获分发许可的音乐素材。
