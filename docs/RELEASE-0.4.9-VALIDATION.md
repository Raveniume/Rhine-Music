## 本地验证

- TypeScript / Vite 生产构建、Windows Rust release 构建通过；场景状态机、GPU 预算和窗口模式共 42 项检查通过，Rust 几何检查 3 项通过。
- 原生 WebView2 在 1280×800、1440×900、1920×1080、1024×768 下运行。三个歌曲选项卡的字号、标题位置一致；详情各行间距一致，八个顶部图标中线一致。
- 使用真实滚轮事件采样标题与 SONG 编号动画；两个歌单入口、50 首分页、12 首单页隐藏分页通过。
- 三次从整体展示进入缓存歌单，实际点击事件至内容可见分别约 65 / 78 / 88 ms。人为延迟曲目响应时，页面外壳约 83 ms 可见；标题遮罩先播放一次，响应返回后标题节点不替换、遮罩不重播。以上是本机合成数据观测，不是网络或所有硬件的保证。
- 歌单页面保留右上角歌词，歌曲详情页隐藏；连续切换整体展示与歌单的逐帧检查没有隐藏帧。频谱使用原全局配置。
- 九个设置分类均可访问，任务栏歌词关闭和重新显示通过；跟随系统、遮罩设置、完整开场重播、QQ / 微信登录方式入口通过。扫码使用合成响应，未验证真实账号授权。
- 任务栏歌词：150% 系统缩放，600×60 物理像素，对应 400×40 逻辑像素，18 CSS px 字体，单行内容完整位于任务栏内。最小化、实际 Alt+Tab 和显示桌面后，原生屏幕命中检查仍命中歌词窗口，且未抢占焦点；停止后隐藏通过。
- 托盘浮窗实测为 540×285 物理像素，位于系统托盘附近且完全落在屏幕工作区内；当前歌曲、歌词同步通过。
- 使用 Windows 原生窗口截图复核深色窗口边缘；未见原来的左侧连续亮线。
- 保留渲染画质参数。优化封面解码对导航的阻塞、重复可见性处理及焦点触发的无效 resize；本轮不宣称跨硬件的固定 FPS 提升。
